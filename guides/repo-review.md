# Course repo review: instructions

**Website:** https://worldbank.github.io/BDA-with-Python
**Repo:** https://github.com/worldbank/BDA-with-Python

Please review the course website and repo as a new participant would, and report anything that's broken, confusing or missing. **Don't edit anything; just report.**

## What to check

1. **Website, every page:** Home, Syllabus, all module pages (0–7), the Setup pages, Resources and About.
   - Do all links and buttons work: slides (English and French), notebooks, Open in Colab, Download?
   - Is anything unclear, out of date, misspelled or inconsistent between pages?
   - Note any "TODO (instructor)" boxes you think we can fill in, and suggest the text.
2. **Setup guide:** follow it on your own machine from start to finish, as a beginner would. Note any step that's unclear, any step that fails, and how long the whole setup took.
3. **Notebooks:** open each notebook on the website and in Colab. Report any that fail to open, show errors, or refer to data files that aren't explained in `data/README.md`.
4. **Repo on GitHub:** read `README.md` and `data/README.md`. Are they clear, and do their links work?
5. **Phone:** open the website on your phone and check that it's readable.

## How to report

Open **one GitHub issue per problem** in the repo (**Issues → New issue**). Each issue should have:

- **Title:** short and specific, e.g. "Module 3: Colab link for wiki-pages is broken".
- **Where:** the page URL or file.
- **What's wrong** and, if you have one, **your suggested fix**.
- A screenshot if it helps.

Add the label `bug` for things that are broken and `enhancement` for improvements. When you've finished, send Dunstan a short summary: how many issues you opened and the top 3 priorities.
